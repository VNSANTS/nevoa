Navegue leve.
Deixe menos rastros.

Um navegador experimental para Android, construído com foco em reduzir o armazenamento local da sessão. Sem conta, sem perfil e sem histórico persistente intencional do aplicativo.

Conhecer o projeto ↗Código no GitHub
⌁

Sessão efêmera

O app limpa histórico, cache e cookies ao encerrar ou limpar a sessão. Armazenamento web persistente fica desativado.

◇

Sem perfil pessoal

Não exige cadastro e não possui backend próprio, analytics ou conta de usuário nesta versão.

↗

Projeto aberto

Estrutura preparada para GitHub Pages e compilação de APK por GitHub Actions. Audite o código antes de confiar nele.

Privacidade não é invisibilidade. O Névoa não promete anonimato absoluto: sites ainda podem ver seu IP e características do navegador; redes, operadoras e serviços podem registrar metadados. O motor usado é o Android System WebView. Não use esta versão como substituto de Tor ou de uma VPN quando precisar deles.
